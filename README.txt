WALLET+ — PREMIER PROTOTYPE PWA

Ce dossier contient une première base installable comme application web (PWA).
Fonctions présentes : interface sombre, carte personnalisable, solde manuel, ajout de revenus/dépenses, historique, statistiques mensuelles simples, objectifs d’épargne, export/import JSON, citations quotidiennes.

Important :
- Aucune connexion bancaire, aucun paiement, aucune donnée de carte bancaire.
- Les données sont stockées localement dans le navigateur de cet appareil.
- Cette première base n'inclut pas encore : Touch ID/PIN, corbeille 30 jours, multi-profils/multi-cartes, code de transfert chiffré, appareil photo, limites budgétaires, édition/suppression des opérations, ni paquet jailbreak .deb.
- Pour installer sur iPhone : héberger ces fichiers en HTTPS, ouvrir l'adresse dans Safari, bouton Partager > Sur l’écran d’accueil.
- Le paquet .deb est un objectif séparé : il nécessitera une adaptation native et une compilation/test sur l'environnement jailbreak ciblé.
